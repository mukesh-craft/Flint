# Task 2 — FizzBuzz
Write a Flint program in `solution.fl` (with `fn main`) that prints, for
i in 1..15, one line each: "Fizz" if divisible by 3, "Buzz" if by 5,
"FizzBuzz" if by both, else the number itself.

Expected output is exactly the 15 lines in expected.txt.
Ideas you'll need: `for`, `%`, `if/elif/else`, `&&`, `print`.
