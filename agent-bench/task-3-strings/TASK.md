# Task 3 — Strings
Write a Flint program in `solution.fl` (with `fn main`) that prints exactly:
- the length of "racecar"
- 1 if "racecar" reversed equals "racecar", else 0
- "racecar" uppercased
- the index of "car" inside "racecar" (or -1)

Ideas you'll need: string methods (`.len()`, `.reverse()`, `.upper()`,
`.indexof()`), `==`, `print`. Try `flintc api strings` for the full list.
